### SwissFEL25 project

- [WENDI2_responsefolding](WENDI2_responsefolding): Code for analysis of the WENDI-2 detector response at the SwissFEL 2025 measurement campaing.
It shows fluences, conversion functions from fluences to H*(10) and detector relative and absolute dose responses. It also calculates the corrections to be applied to the dose measurements for different particle types.
- [SwissFEL_frequencydata](SwissFEL_frequencydata): Frequency data from the SwissFEL log files during 2025 data taking.
- [SwissFEL_currentdata](SwissFEL_currentdata): Current data from the SwissFEL log files during 2025 data taking.
- [WENDI_data](WENDI_data): Data for the WENDI-2 detector during 2025 data taking.
- [LUPIN_data](LUPIN_data): Data for the LUPIN detector during 2025 data taking.
- [MultiDetectorAnalysis.py](MultiDetectorAnalysis.py): Python code for the analysis at 10 and 25 Hz of the detectors used during the 2025 data taking.
